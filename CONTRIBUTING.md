# Contributing

Detail Drift is currently a research plan rather than a released implementation. Contributions are most useful when they improve the scientific design or reproducibility without overstating preliminary evidence.

## Useful contributions

- Point out closely related work, especially reference-grounded long-video evaluation.
- Propose legally usable product-image/video datasets.
- Review metric failure modes under viewpoint, lighting, motion blur, and occlusion.
- Suggest stronger baselines or statistical tests.
- Report unclear claims, broken links, or documentation problems.

## Before opening a change

1. Separate verified evidence from hypotheses or proposed work.
2. Link primary sources for technical claims whenever possible.
3. Do not add product media unless its license and provenance are documented.
4. Do not commit model weights, generated datasets, credentials, or private interview data.
5. For experiments, record model revision, environment, seed, prompt, generation settings, and hardware.

## Research conduct

Human-study materials and any customer-discovery data must follow applicable ethics, consent, privacy, and institutional review requirements. Generated samples should be clearly identified as synthetic.

## Licensing note

No repository license has been selected yet. External code or data should not be merged until compatible licensing and attribution have been reviewed.
